# The Catacombs

A first-person exploration game set in the Paris Catacombs. Bone-walled tunnels, a weak flashlight, and five sealed gates between you and the way up. Runs fully offline in one HTML file, on desktop and phone.

Play: https://optimusgrok.github.io/the-catacombs/

Desktop: WASD to walk, mouse to look, E to interact, I or Tab for the satchel, M for the map, F for the flashlight.
Phone: left thumb to walk, right thumb to look, USE to interact.
